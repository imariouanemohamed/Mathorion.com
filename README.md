# Mathorion.com

The official website foundation for Mathorion: short mathematics challenges and visual explanations.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `npm run dev` — start the local development server
- `npm run lint` — run ESLint
- `npm run build` — create a production build
- `npm run start` — serve the production build

Video records live in `data/videos.ts`. Social profiles live in `data/socials.ts`; unresolved profile URLs intentionally use `null` until official links are confirmed.
